Personal iOS package repository

jjolano

Open-source packages for jailbroken iOS. Supports rootful (iphoneos-arm), rootless (iphoneos-arm64), and roothide (iphoneos-arm64e).

Add the repo

Tap the button for your package manager to add this repository to your device.

Zebra Lightweight, modern package manager. zbra://sources/add/https://ios.jjolano.me Sileo Modern default for newer jailbreaks. sileo://source/https://ios.jjolano.me Cydia The classic package manager. cydia://url/https://cydia.saurik.com/api/share#?source=https://ios.jjolano.me Installer 5 An alternative package manager. installer://add/repo=https://ios.jjolano.me

On your iPhone, tapping a button opens the app with this repository added. From a computer, copy the link and paste it into your package manager, or manually add https://ios.jjolano.me in its sources screen.

Supported variants

Packages are built for the architectures your jailbreak uses. Current packages (HookKit 2.x, Shadow 4.x) cover all three; older ones are rootful/rootless only.

  • Rootful iphoneos-arm The traditional layout, where the root filesystem is writable.
  • Rootless iphoneos-arm64 The default on modern jailbreaks; installed under /var/jb.
  • Roothide iphoneos-arm64e A rootless-style layout that hides the jailbreak from apps.
